# Agent Rules & Guidelines

## Coding Guidelines Compliance
Before starting any feature development or making modifications to the codebase, you MUST:
1. Read the `coding_guidelines.md` file in the root of the repository.
2. Ensure that a User Story exists as a GitHub Issue and is written in English.
3. Adhere to the defined branching model by using branch names formatted as `feature/US-[ID]-...` or similar.
4. Use Conventional Commits for all commit messages.
5. Update the `README.md` and `CHANGELOG.md` as required by the Definition of Done before finalizing the task.
