## User Story
As a user, I want the application to be free of unnecessary developer logging features so that the UI remains clean and resource usage on the watch and phone is optimized.

## Background / Context
In previous stories (such as US-26 and US-31), we implemented a comprehensive logging system accessible via the settings page to debug application crashes. Since these developer-centric features are no longer relevant for the end-user in regular usage, they should be removed to simplify the codebase and settings interface.

## Acceptance Criteria
- [ ] Remove all logging-related UI elements (e.g., visible log levels, "Delete Logs" button) from the Settings Page (HTML/JS).
- [ ] Remove the logging logic, persistence mechanisms, and message handlers from the PebbleKit JS codebase.
- [ ] Remove the corresponding logging macros and transmission logic from the C codebase on the watch.
- [ ] Ensure that removing these features does not break any existing functionality, especially the workout session persistence and watch-phone communication.
- [ ] Update `CHANGELOG.md` to reflect the removal of the logging feature.
